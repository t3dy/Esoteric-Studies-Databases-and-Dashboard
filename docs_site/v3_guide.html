Version 3.0: Hermetic Convergence

Status: Current Production

Overview

V3 transforms the engine into a Digital Humanities platform. It adds Visual Intelligence (Image Vault), Pedagogical transparency (code-as-text), and Agentic Mining.

New Features

🖼️ The Image Vault (Mutus Liber)

URL: /gallery

A "Pinterest-style" gallery of thousands of images extracted automatically from the PDF corpus. Use this to study visual motifs in alchemical texts without opening individual files.

🎓 Digital Humanities Pedagogy

URL: /dh

A "Story of Learning" page that exposes the backend code (agentic_pipeline.py) as a primary source, teaching users about the algorithmic choices behind the history.

🕯️ Lumina Theme Switcher

Click the Esoteric Studies logo in the top-left sidebar to toggle between:

  • Light Mode: Standard academic interface.
  • Grimoire Mode: Parchment backgrounds and serif typography.

Agentic Workflow

V3 replaces static scripts with intelligent Agents:

  • Lawrence (Chymistry): Extracts chemical recipes.
  • Pamela (Artisanship): Identifies tools and workshops.
  • Historiography Scorer: Rates texts on their "Empiricism" vs. "Tradition".

Technical Note

All V3 data is anchored by a run_id, allowing for safe rollbacks if the mining agents hallucinate relationships.
