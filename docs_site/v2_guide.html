Version 2.0: The Graph

Status: Active (Foundational Layer)

Overview

V2 introduced the Knowledge Graph, moving beyond file storage to understanding entities (Scholars, Concepts) and their relationships.

Key Concepts

1. Named Entity Recognition (NER)

The system automatically scans PDFs for names like "Isaac Newton" or "Hermes Trismegistus" and links them to a canonical entity_id.

2. Inquiry Analysis

The system parses user chat logs to extract Questions. It categorizes them into "Moves" such as:

  • Methodology Analysis
  • Bibliographic Inquiry
  • Concept Definition

Using the V2 Dashboard

  • Knowledge Tab: Browse by Scholar. See which chats discuss "Frances Yates".
  • Popularity Contest: A visualization showing which topics are most frequently queried.
  • Hall of Designers: Verify the architectural health of the system.
