Version 1.0: The Archive

Status: Deprecated (Superseded by V2/V3)

Overview

V1 focused on establishing a clean "Source of Truth" for the file system. It replaced chaotic filenames with standardized, distinct titles.

Database Schema (Legacy)

  • titles: The core table mapping file paths to IDs.
  • categories: Basic folder-based categorization (e.g., "Alchemy", "Gnostic").

Workflow

  1. Renaming: Run rename_exec.py to normalize PDF filenames (removing underscores, etc.).
  2. Scanner: Run scanner.py to crawl the directory and populate the SQLite database.

Dashboard Features

The V1 Dashboard (Legacy View) provided:

  • Library Browser: A simple grid of PDF cards.
  • Search: Basic SQL LIKE query on titles.
